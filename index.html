暴風雨後的街道

暴風雨後的街道中二寫作　重溫步移法．定點描寫．直接、間接、比喻描寫

正在佈置街道……
家門口
我的路線（步移法）
已完成 0 / 8
拖曳畫面可轉換視角
昨夜十號風球．今早風球除下

你踏出家門，準備上學……

街道已經面目全非。沿路觀察暴風雨留下的痕跡，收集描寫句子，走到學校門口。

  1. 方向鍵或 WASD 行走；拖曳畫面轉換視角；也可直接點擊地面行走。
  2. 跟着地上的黃色箭咀，依次找出編號 ①至⑧；編號就是紀錄表的行數。走近後按空格鍵或「查看」按鈕。
  3. 把例句抄在筆記上，寫出它用了直接、間接還是比喻描寫。答案最後才核對。
  4. 巴士站地上有一個黃色虛線圈「定點觀察點」，記得站上去。

課堂用法：重溫五種寫作手法

  1. 步移法：畫面頂部記下你走過的路線；到學校門口，路線就變成文章的段落次序。
  2. 定點描寫：巴士站的黃色虛線圈是「定點觀察點」，站上去後鏡頭變成「我」的眼睛，只移動視線，由近至遠（或由遠至近）。
  3. 直接、間接、比喻描寫：每樣景物都有一句例句，學生抄在筆記上，寫出它用了甚麼手法。
  4. 預設「課堂模式」只顯示紀錄表要寫的 ①至⑧，並有箭咀帶路；按「課堂模式」可切換為自由探索，顯示全部景物。
  5. 老師先投影示範第 ① 項，學生再自己玩；最後打開「筆記簿」按「核對答案」。
  6. 「AI 寫作教練」可即場評學生自己寫的句子。
